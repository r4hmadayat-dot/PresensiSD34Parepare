PAKET PWA SIAP UPLOAD KE GITHUB PAGES

Repository tujuan:
https://github.com/r4hmadayat-dot/PresensiSD34Parepare

UPLOAD KE ROOT REPOSITORY (bukan ke folder lain):
- index.html
- config.js
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

config.js SUDAH DIISI DENGAN URL DEPLOYMENT TERBARU:
https://script.google.com/macros/s/AKfycbwrgQBoJ_nxiOMt996nlRWrR-IoWqPOnkTj_aMTRgxozAZcMSGGXpbS3jGM5sobp7uynw/exec

Setelah upload:
1. Commit changes.
2. GitHub -> Settings -> Pages.
3. Source: Deploy from a branch.
4. Branch: main.
5. Folder: /(root).
6. Save.
7. Buka:
   https://r4hmadayat-dot.github.io/PresensiSD34Parepare/

Jika pernah membuka versi PWA lama, hapus shortcut/PWA lama atau clear site data/service worker sebelum pengujian ulang.

JANGAN upload folder AppsScript ke GitHub Pages.
JANGAN mengganti config.js dengan URL /dev.
