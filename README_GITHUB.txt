PWA GitHub Pages Fix

1. Upload ALL contents of this folder to the ROOT of the GitHub repository.
2. Required root files:
   index.html
   config.js
   manifest.webmanifest
   sw.js
   icons/icon-192.png
   icons/icon-512.png
3. Do NOT upload the AppsScript folder to GitHub Pages.
4. config.js is already set to the provided /exec URL.
5. After commit, GitHub Pages should publish from main / (root).
6. If an old PWA was installed, uninstall/remove the old shortcut and clear site data before testing the new one.
